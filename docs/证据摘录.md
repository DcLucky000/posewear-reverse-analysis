### 6.2 本站代理 ` /api/proxy `

- 实现：官方仓 `functions/api/proxy.js`（Cloudflare Pages Function，`export async function onRequest`）。
- 线上探测（无 Origin，2026-11-24）：`OPTIONS` → 204；`GET`/`POST` → 403 JSON `{"error":{"message":"只接受本站页面发起的请求"}}`。符合源码 `sameSite`（校验 `Origin` / `Referer` 与本站同源）。
- 前端调用：`fetch('/api/proxy', { headers: { 'x-target-url': <https目标>, 'x-proxy-kind': 'image'|缺省, 'x-proxy-custom': '1'（自定义中转）, 以及原鉴权头 } })`。
- 可观察限制（读公开源码，不写绕过）：仅 GET/POST；目标必须 HTTPS；官方接口不允许非标准端口、不允许 URL 内嵌账号密码；官方路径须匹配 `/api/v3|v1|v1beta/.../(images/edits|images/generations|models/...[:generateContent])`；非官方中转须设置里选「自定义」且 origin 落入环境变量 `POSEWEAR_PROXY_ORIGINS`；图片下载（`x-proxy-kind=image`）仅 GET，且 host 须在 `oaidalleapiprodscus.blob.core.windows.net` / `*.volces.com` / `*.bytepluses.com` / `*.googleusercontent.com`；转发头仅 `accept`、`content-type`、`authorization`、`x-goog-api-key`；限流约每 IP 每 60 秒 API 20 次、图片 40 次；错误为 JSON `{error:{message}}`，响应 `cache-control: no-store`。

生产环境该环境变量的具体值未知。本次未带 Origin、也未尝试转发任何真实 Key 或构造绕过。

### 6.3 本机引擎 `/api/local/*`

- 前端：`GET /api/local/status`（头 `x-posewear-local: 1`）；`POST /api/local/generate`（multipart 表单，同源头）。
- 线上：`GET` 返回站点 404 HTML；`POST` 探测为 405。**生产未部署该 Function。**
- 官方 `docs/local-engines.md`：`npm start` 预览把请求转到本机 ComfyUI（约定节点标题 PoseWear Prompt / Image N / Output / Size / Seed）或 sd-cpp 的 `/v1/images/edits|generations`。可用 `POSEWEAR_LOCAL_ENGINE`、`POSEWEAR_LOCAL_URL`。

## 7. 提示词模式概要（不抄全文）

`studio.js` 的 `compose(poseSet, state)`：

1. 若几乎未选素材，则退回用户附加说明 `extra`，或仅风格/自定义人物句。
2. 否则按参考图计数器 `rng` 分配「第 N 张 / image N」。顺序大致为：人物照片或库内人像 → 服装（写实或动画，工作台最多约 2 套）→ 姿势（可多张/多机位，选择态上限约 6）→ 表情（约 1）→ 其他素材（`MATERIAL_ROLES`：发型、场景、光影、道具、家具）。
3. 试穿条件可观察为「有人物且有服装且 mode=tryon」；此时英文引导语以 “Fashion virtual try-on using reference images” 一类句式开头（中文有对应句，此处不逐字转录长模板）。
4. `keepBg`：试穿且未选场景/光影时，要求保持原照背景。
5. `STYLES`、`CHARS` 为预设对（内部 id + 中文名 + 中英描述）。只记存在风格如 `keep`（照片质感）、人物如 `asia`（东亚女性），不抄描述段落。
6. `wbNeutral` 打开时，发送前改写成中性电商试穿描述（产品文案：不改变服装和姿势；用于减少误拦截，不是绕过审核）。
7. 复制组合提示词时，`references.js` 的 `formatBrief` 在正文下追加「参考图」列表：`图 N · 库名 · 标题 · 角度 — URL`；本地上传照则提示另附文件。

语言：界面 zh/en/ja；素材描述复制与出图语言主要是 zh/en（`wbPl` / `pl`）。页脚也提示 SD 类模型用英文更准。
